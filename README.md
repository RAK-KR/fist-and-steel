# FIST & STEEL

코드로 찍은 도트 그래픽의 2D 격투 게임입니다. 맨손 권법가 무혁과 검객 세린이 싸웁니다.

## 플레이 주소

https://rak-kr.github.io/fist-and-steel/

(저장소 이름을 다르게 만들면 주소의 `fist-and-steel` 부분이 저장소 이름으로 바뀝니다.)

## 모드

- CPU 대전 (쉬움 / 보통 / 어려움)
- 2인 대전 (한 키보드 또는 게임패드 2개)
- 트레이닝 (연습 상대 설정, 판정 박스 보기, 콤보 데미지 표시)

## 조작

| | 1P | 2P |
|---|---|---|
| 이동 | W A S D (혼자 할 때는 방향키도 됨) | 방향키 |
| A 버튼 | J | . 또는 Num1 |
| B 버튼 | K | / 또는 Num2 |

- 점프 ↑, 앉기 ↓, 가드는 상대 반대쪽 누르기 (하단은 ↙)
- 대시 →→, 백대시 ←←, 일시정지 Esc
- 게임패드: 방향 + X/A = A, Y/B = B, Start = 일시정지
- 모든 화살표 커맨드에서 →는 상대 쪽 방향입니다.

## 기술

**무혁** — 붕격 ↓↘→ + A / 올려치기 →↑ + A / 회전 뒤차기 ↓↙← + B
**세린** — 검기 ↓↘→ + A / 섬광 →→ + A / 초승달 →↑ + A

기본기가 맞거나 막히면 기술로 바로 캔슬할 수 있습니다. 전체 기술표는 게임 안 메뉴의 "조작법 · 기술표"에 있습니다.

## 파일 구조

```
index.html
css/style.css
js/config.js     버전, 화면 크기, 체력 등 기본 설정
js/rig.js        뼈대 → 도트 변환 렌더러
js/fighters.js   캐릭터 모양(몸, 옷, 무기, 색)
js/anims.js      모든 동작의 키 포즈
js/moves.js      프레임 데이터(발생, 지속, 경직, 데미지)
js/bake.js       시작할 때 모든 프레임을 미리 그림
js/input.js      키보드 / 게임패드
js/sim.js        60프레임 고정 전투 시뮬레이션
js/ai.js         CPU
js/audio.js      효과음 (파일 없이 합성)
js/render.js     스테이지, 이펙트, HUD
js/main.js       메뉴와 게임 루프
```

버전: v0.1.0 (업데이트할 때 index.html의 `?v=` 값과 config.js의 버전을 같이 올리면 예전 파일이 섞이지 않습니다.)
